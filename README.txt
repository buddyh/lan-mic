Lan Mic 0.3.0 — Rust microphone handoff

The complete installation, configuration, troubleshooting, testing and uninstall
guide is README.md in this directory. It covers Mac ↔ Linux and Linux ↔ Linux,
menu-bar display preferences, prerequisites, and the exact validation limits.

Mac window: Settings… from the menu bar or reopen Lan Mic from Applications.
About: About Lan Mic in the window or standard app menu.
Menu bar labels: choose Computer names or Mac / Linux in the window.
Linux status: ~/.local/share/lan-mic/lan-mic receiver --status
Setup check: lan-mic doctor
LAN Mouse peer IDs: lan-mic peers

Mac receiving needs BlackHole 2ch and its requested restart.  See VALIDATION.txt for test evidence.
